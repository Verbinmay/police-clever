Чат/тема регистрируется в этом списке автоматически, как только кто-то написал в неё — по умолчанию бот молчит. Включите нужные тумблеры отдельно: AI-шутки (триггер-слово + гача, платно), Да/Нет (бесплатный флейвор на слова "да"/"нет", без AI) и/или Голосование за мьют — независимо друг от друга ("подчаты" = форум-темы внутри супергруппы; для обычной группы без форума — единственная строка с thread_id=0). Название темы можно задать прямо из чата командой /th Имя.
