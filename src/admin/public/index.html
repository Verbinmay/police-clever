Реван — админка

Чат/тема регистрируется в этом списке автоматически, как только кто-то написал в неё — по умолчанию бот молчит. Включите нужные тумблеры отдельно: AI-шутки (триггер-слово + гача, платно), Да/Нет (бесплатный флейвор на слова "да"/"нет", без AI) и/или Голосование за мьют — независимо друг от друга, и только в конкретной теме. Кликните по чату, чтобы развернуть его темы ("подчаты" = форум-темы внутри супергруппы; для обычной группы без форума — единственная строка "вся группа"). Название темы можно задать прямо из чата командой /th Имя. Учёт дней рождения — отдельный тумблер прямо в заголовке чата (не темы): он на весь чат сразу, во всех его подчатах, см. вкладку "Дни рождения".

Стикер-заглушка

Если позвали по имени (не гачей), а лимит (кулдаун/дневной кап/месячный бюджет) уже исчерпан — вместо тишины отправляется случайный стикер отсюда. Короткое имя пака — из ссылки t.me/addstickers/<имя>. Пусто = фолбэк выключен. Пак можно обновлять когда угодно, бот подхватит новые стикеры в течение часа без перезапуска.

Сценарии (пассивная гача)

Один общий пул — каждый вызов случайно выбирает сценарий среди наименее использованных (без деления на категории/тона). Можно использовать плейсхолдер {target} — тогда подставляется случайный "активный" участник (или тот, кто позвал бота по имени).

Использование сценариев

Сколько раз реально выпадал каждый сценарий (см. scenario.ts — shuffle-bag по минимальному счётчику: разброс использований никогда не превышает 1). Для контроля, что распределение честное, а не только "по задумке".

Гача — вероятность пассивного срабатывания

Бот пассивно запоминает участников чата (id/имя/username) и раз в двое суток обновляет дату рождения напрямую из профиля Telegram (структурированное поле "Дата рождения", не текст — никакого AI-угадывания). Пол Telegram как атрибут профиля не хранит вообще — задаётся только вручную. Тумблер "Дни рождения" — в заголовке чата на вкладке Подчаты, один на весь чат, не на отдельную тему. Дату, заданную здесь вручную, автообновление больше никогда не трогает. Поздравление в день рождения генерирует AI по промпту ниже и уходит в общий чат.

Промпт поздравления

{name} — имя именинника, {gender} — "мужской"/"женский"/"неизвестен" (для согласования рода в тексте).

Проверить, что реально сгенерирует AI — без отправки в чат (но реальный AI-вызов, расходует бюджет как обычно).

Добавить участника вручную

Для тех, кого бот сам не найдёт (дата не заполнена в профиле, настройки приватности) — можно завести карточку самостоятельно, включая пол (Telegram его не хранит вообще). tgId — числовой Telegram id (его можно узнать, например, у @userinfobot).
