# Реван (police-clever v2)

Telegram-бот-персона для групповых чатов: AI-шутки на дешёвой LLM (DeepSeek)
+ голосование чата за мьют. Никакого командного интерфейса модерации —
всё управление (какие чаты/темы бот обслуживает, промпты, правила
голосования) происходит через встроенную веб-админку.

Переписан с нуля с TDLib-userbot на официальный Telegram Bot API, на
архитектуре, взятой из другого проекта — `bots-platform` (один
Telegraf-бот на вебхуке + Express + TypeORM + встроенная админка в одном
процессе).

## Что делает бот

- **AI-шутки** — по триггер-слову (по умолчанию "Реван") в любом
  сообщении, плюс пассивная "гача" — растущий шанс, что бот сам вставит
  AI-шутку в разговор. Контекст — последние 4 сообщения темы.
- **Голосование за мьют** — реплай спецфразой (по умолчанию `/mutevote`)
  на сообщение нарушителя открывает 5-минутное голосование кнопками
  "Да"/"Нет". При кворуме (по умолчанию 3+ "да", и да>нет) — бот мьютит
  цель на настраиваемое время.
- **Дни рождения** — пассивно запоминает участников (id/имя/username) и
  раз в двое суток пытается по сообщениям определить пол и дату рождения
  (AI-скан); дату, заданную вручную в панели, автоскан больше не трогает.
  В сам день рождения бот шлёт в общий чат AI-сгенерированное
  поздравление по промпту, редактируемому в панели.
- Всё это **выключено по умолчанию** в каждой новой теме/чате, пока
  суперадмин не включит явно в панели.

## Настройка бота в Telegram

1. Создать бота через [@BotFather](https://t.me/BotFather), получить `BOT_TOKEN`.
2. **Обязательно выключить Privacy Mode** (`/setprivacy` → Disable) —
   иначе бот не увидит обычные сообщения в группе, только команды и
   упоминания. Без этого не работают ни AI-шутки, ни голосование.
3. Добавить бота в группу **с правом "Ограничивать участников"**
   (restrict members) — без этого права `restrictChatMember` (мьют) не
   сработает.
4. Написать в чат что угодно — чат и тема (или "вся группа" для
   нефорумных чатов) сразу появятся в админ-панели, во вкладке "Подчаты".
   Включить там нужные тумблеры.

## Переменные окружения

См. [.env.example](.env.example). Обязательно сгенерировать случайные
`WEBHOOK_SECRET_TOKEN` и `SESSION_SECRET` (например `openssl rand -hex 32`).

`DEEPSEEK_API_KEY`/`OPENAI_API_KEY` — оба опциональны, но заполните хотя бы
тот, который реально используете. Какой из них активен прямо сейчас
(baseURL/модель/цена за токен тоже) — переключается в панели без
передеплоя, см. ниже.

## Запуск локально

```bash
cp .env.example .env   # заполнить токены
docker compose up -d --build
```

Для вебхука нужен публичный HTTPS-адрес — для локальной разработки
поднимите туннель (`ngrok http 3000` / `cloudflared tunnel`) и укажите его
в `WEBHOOK_BASE_URL`.

Без Docker (нужен отдельно поднятый Postgres):

```bash
npm install
npm run typecheck
npm run dev
```

## Админ-панель

`https://<ваш домен>/` — вход по логину/паролю. Первый аккаунт создаётся
автоматически из `ADMIN_BOOTSTRAP_USERNAME`/`ADMIN_BOOTSTRAP_PASSWORD` при
пустой таблице аккаунтов, дальше добавляйте/удаляйте аккаунты прямо в
панели (вкладка "Аккаунты") — без правки env и передеплоя. Все аккаунты
равноправны (полный доступ ко всем чатам).

Вкладки: **Подчаты** (какие чаты/темы обслуживает бот), **AI-конфиг**
(провайдер DeepSeek/OpenAI + месячный $ лимит, промпт-персона, категории
тона шуток general/targeted/sarcasm/praise с весами, триггер-слово,
кривая гачи, статистика использования каждого сценария), **Голосование**
(спецфраза/кворум/окно/длительность мьюта), **Статистика AI**
(звонки/токены/оценочные $ по дням и по чатам, остаток месячного бюджета),
**Голосования** (история), **Дни рождения** (таблица участников с
редактируемой датой + промпт поздравления), **Логи** (вообще все действия
бота), **Аккаунты**.

### Стоимость AI под контролем

Частота AI-ответов не растёт линейно с активностью чата — четыре
независимых рычага (все настраиваются в панели): контекст режется по
бюджету символов вместо "последних N сообщений", персистентный кулдаун
между **любыми** AI-ответами в чате, дневной кап
вызовов на чат, и глобальный (на весь бот) месячный $ потолок — как
только фактическая (оценочная) стоимость с начала месяца достигает
лимита, AI-ответы приостанавливаются до следующего месяца.

## Структура

```
src/
  index.ts, config.ts        — точка входа, единый конфиг
  create-bot-app.ts           — бутстрап: Telegraf на вебхуке + Express + БД
  bot-context.ts, bot-part.ts — общий тип контекста и интерфейс "часть бота"
  db/                         — сущности (EntitySchema)/репозитории
  logger/                     — логгер, пишет и в stdout, и в БД (part_logs)
  parts/
    core/       — пассивная регистрация чата/темы, лог сообщений, крон чистки
    ai-fun/     — AI-шутки (триггер-слово + гача)
    mute-vote/  — голосование за мьют
    birthdays/  — учёт участников/дат рождения (AI-скан раз в 48ч) + поздравления
  admin/        — веб-панель (сессии + routers + статика), в том же процессе
```

`synchronize: true` в TypeORM — сознательно, без миграций (масштаб
проекта не требует). Автотестов нет — по решению.

## Деплой

`Dockerfile`/`docker-compose.yml` — как для локального запуска, так и как
основа для прода (свой Postgres). Если есть общий VPS-стек (Postgres/Caddy)
уже под другими ботами — смотрите `docker-compose.prod.yml` в
`bots-platform` как образец подключения к внешним `edge`/`db-net` сетям
вместо поднятия своего Postgres.
